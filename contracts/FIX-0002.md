# CONTRACT: El ID de sala del modo Companion es predecible
# ID: FIX-0002
# Status: RESOLVED
# Mode: LOOP
# Gate-Mode: EXPRESS

## Intent
`createRoom` genera el ID de sala con `Math.random()` (6 caracteres A-Z0-9, unas 2,2×10⁹ combinaciones) y el documento `rooms/{id}` contiene las credenciales de WooCommerce del host. Un ID corto y no criptográfico facilita acceder a una sala ajena. Alcance: solo la generación del ID. Fuera de alcance: reglas de Firestore y autenticación de `joinRoom` (ver FIX-0003).

## Reproduction Steps
1. Mockear Firestore y llamar `createRoom` (`services/realtimeSession.ts`) varias veces.
2. Recolectar los `roomId` devueltos y medir su longitud y alfabeto.
3. Espiar `Math.random` durante la llamada y comprobar si se invoca.

## Current Behavior
El ID es `Math.random().toString(36).substring(2, 8).toUpperCase()` (línea 16): 6 caracteres, ~31 bits, generados con un PRNG no criptográfico. Se transmite por QR como `?joinRoom=<id>` (`HostRoomModal.tsx`, línea 55) y `MobileJoinScanner.tsx` (líneas 33-45) lo lee sin validar formato ni longitud, así que un ID más largo es compatible sin tocar el escáner.

## Expected Behavior
El ID tiene al menos 128 bits de entropía, sale de un generador criptográfico y es seguro para URL. El flujo por QR sigue funcionando igual.

## Business Rules
- BR-001: `roomId` debe tener al menos 128 bits de entropía.
- BR-002: `roomId` debe generarse con `crypto.getRandomValues`; `Math.random()` no debe usarse para identificadores de sala.
- BR-003: `roomId` debe contener solo caracteres `[A-Za-z0-9_-]` para viajar en `?joinRoom=` sin escape.

## Acceptance Criteria
- AC-001: GIVEN Firestore mockeado WHEN se llama `createRoom` THEN el `roomId` devuelto coincide con `^[A-Za-z0-9_-]{22,}$`.

- AC-002: GIVEN Firestore mockeado WHEN se llama `createRoom` 10.000 veces THEN no hay `roomId` repetidos.
- AC-003: GIVEN `Math.random` espiado WHEN se llama `createRoom` THEN `Math.random` no es invocado.
- AC-004: GIVEN un `roomId` devuelto por `createRoom` WHEN se arma la URL `?joinRoom=<id>` y se lee con `URLSearchParams` THEN el valor leído es idéntico al `roomId`.
