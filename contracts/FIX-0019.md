## Intent
Una utilidad de "auditoría silenciosa" resuelve la IP pública del usuario consultando un servicio externo (`api.ipify.org`) y la persiste junto con metadatos en `localStorage`. Se dispara al importar una planilla y al agotar reintentos de conexión. No hay aviso, base legal, propósito documentado ni forma de desactivarla: es una dependencia de privacidad no declarada en una app que se presenta como client-side.

## Reproduction Steps
1. Abrir la app y la pestaña Network.
2. Importar cualquier archivo `.xlsx` en la pestaña **Importar → Planilla Excel**.
3. Observar el request a `https://api.ipify.org/?format=json`.
4. Inspeccionar `localStorage['wootag_sl']`: hay entradas con `ip`, `type`, `meta` y timestamp.

## Current Behavior
- `utils/ipLogger.ts` consulta `api.ipify.org` con caché de 30 min y guarda hasta 200 eventos.
- `components/controls/ImportTab.tsx` llama `logEvent('xls_upload', { f: file.name, n: ... })`.
- `components/ConnectionModal.tsx` llama `logEvent('auth_fail_limit', { u: config.url, ... })`.
- `getSecurityLog()` no se usa en ninguna pantalla: los datos se registran y nunca se muestran.

## Expected Behavior
La app no contacta servicios de terceros para obtener la IP ni persiste direcciones IP. Si se necesita telemetría de diagnóstico, debe ser local, sin IP, con propósito documentado y desactivable.

## Business Rules
- BR-001: Ningún request a `api.ipify.org` (ni a otro servicio de geolocalización/IP) desde ningún flujo.
- BR-002: No se persiste la IP del usuario en `localStorage` ni en Firestore.
- BR-003: Los errores de conexión y de importación siguen siendo diagnosticables (logs locales sin datos personales).
- BR-004: La documentación de seguridad refleja el cambio.

## Acceptance Criteria
- AC-001: GIVEN cualquier flujo de la app (subir XLS, fallo de conexión) WHEN se inspecciona el tráfico THEN no hay requests a `api.ipify.org` ni a servicios equivalentes.
- AC-002: GIVEN el uso normal de la app WHEN se inspecciona `localStorage` THEN no existe ninguna clave con direcciones IP.
- AC-003: GIVEN el código WHEN busco `ipify`/`ipLogger` THEN no quedan llamadas activas (o el módulo fue eliminado).
