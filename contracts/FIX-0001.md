# CONTRACT: La API key de Gemini queda embebida en el bundle público
# ID: FIX-0001
# Status: RESOLVED
# Mode: LOOP
# Gate-Mode: EXPRESS

## Intent
`vite.config.ts` inyecta `GEMINI_API_KEY` en el JavaScript del cliente mediante `define`, por lo que cualquier visitante del sitio puede extraerla y consumir la cuota. La key debe dejar de viajar en el bundle sin perder la optimización de descripciones con IA (o decidiendo explícitamente qué pasa con esa función).

## Reproduction Steps
1. Exportar `GEMINI_API_KEY=KEY_DE_PRUEBA_123` en el entorno de build (o en `.env`).
2. Ejecutar `npm run build`.
3. Ejecutar `grep -rl "KEY_DE_PRUEBA_123" dist/` y revisar el resultado.

## Current Behavior
La cadena aparece en `dist/assets/index-*.js` (verificado el 2026-10-10 buildeando con una key ficticia). Causa: `vite.config.ts` (líneas 18-19) define `process.env.API_KEY` y `process.env.GEMINI_API_KEY` con el valor real, y `services/geminiService.ts` (línea 5) la lee en el navegador y llama a Gemini directo desde el cliente. En CI, el secret `ENV_FILE` se escribe como `.env` antes de `npm run build`: si ese secret incluye `GEMINI_API_KEY`, la key está hoy en el sitio de producción (no pude verificar el contenido del secret).

## Expected Behavior
Ningún archivo de `dist/` contiene la key. La optimización de descripciones permite BYOK vía `localStorage` o fallback a la descripción original si no está configurada, sin lanzar excepciones no capturadas.

## Business Rules
- BR-001: `vite.config.ts` no debe inyectar `GEMINI_API_KEY` ni `API_KEY` en el bundle del cliente.
- BR-002: Si la optimización con IA no está disponible, `optimizeDescription` devuelve la descripción original y no lanza excepción (comportamiento actual a preservar).

## Acceptance Criteria
- AC-001: GIVEN `GEMINI_API_KEY=KEY_DE_PRUEBA_123` en el entorno de build WHEN termina `npm run build` THEN ningún archivo de `dist/` contiene `KEY_DE_PRUEBA_123`.
<!-- Este AC debe FALLAR hoy y PASAR después del fix -->
- AC-002: GIVEN la optimización con IA no disponible (sin configurar o con error de la API) WHEN el usuario pide optimizar la descripción de un producto THEN el producto conserva su descripción original y no se produce una excepción sin capturar.
