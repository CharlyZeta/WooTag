# CONTRACT: El proyecto tiene 9 errores de tipos y el CI no verifica tipado
# ID: FIX-0009
# Status: RESOLVED
# Mode: LOOP
# Gate-Mode: EXPRESS

## Intent
`npx tsc --noEmit` reporta 9 errores. Vite transpila sin verificar tipos, `package.json` no tiene un script de tipado y el CI (`deploy.yml`) no lo ejecuta, así que los errores llegan a producción sin que nada los frene. Fuera de alcance: activar `strict` en `tsconfig.json` (medido el 2026-10-10: `tsc --strict` da 1221 errores; sería un work item aparte).

## Reproduction Steps
1. Ejecutar `npm ci`.
2. Ejecutar `npx tsc --noEmit`.
3. Contar las líneas `error TS` de la salida.

## Current Behavior
Salida verificada el 2026-10-10, 9 errores:
- `App.tsx(404)`: TS2304, `UserCloudProfile` no está importado.
- `components/HostRoomModal.tsx(12)`: TS2304, `Product` no está importado.
- `components/controls/ImportTab.tsx(152, 157, 160)`: TS2741 y TS2339, el tipo `WooCategory` (`types.ts`) no declara `parent`, que la API de WooCommerce sí devuelve.
- `components/controls/ImportTab.tsx(251, 252)`: TS2698 y TS2339, spread sobre un valor de tipo `unknown`.
- `services/cloudProfiles.test.ts(22)`: TS2556, argumento spread sin tipo tupla.
- `services/wooService.test.ts(84)`: TS2322, el mock de `fetch` no es asignable al tipo de `fetch`.
`package.json` no define `typecheck` y `deploy.yml` ejecuta `npm run test` y `npm run build`, pero no `tsc`. Los 97 tests pasan y el build compila pese a los errores.

## Expected Behavior
`npx tsc --noEmit` termina con 0 errores, existe `npm run typecheck`, y el workflow de deploy corre el chequeo de tipos antes de construir y desplegar. El comportamiento en runtime no cambia.

## Business Rules
- BR-001: `npx tsc --noEmit` debe terminar con 0 errores, incluyendo los archivos de test.
- BR-002: `package.json` debe exponer el script `typecheck` con el valor `tsc --noEmit`.
- BR-003: El workflow de deploy no debe construir ni desplegar si `npm run typecheck` falla.
- BR-004: Corregir los errores no debe cambiar el comportamiento en runtime: los tests existentes siguen pasando sin modificar sus aserciones.
