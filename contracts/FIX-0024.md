# CONTRACT: Tailwind se carga por CDN y las fuentes por @import externo en producción
# ID: FIX-0024
# Status: DRAFT
# Mode: GATE
# Gate-Mode: STRICT

## Intent
La build de producción no genera CSS: todo el estilo de la app depende de `https://cdn.tailwindcss.com`, que compila Tailwind en el navegador en cada visita, y de un `@import` a Google Fonts dentro de `<style>`. Son dos dependencias de terceros bloqueantes en el arranque, sin SRI, incompatibles con el uso offline y contradictorias con el discurso "app estática hosteable en cualquier WordPress". Además el CSS crítico no es auditable ni versionable.

## Reproduction Steps
1. Ejecutar `npm run build` y listar `dist/`: no hay ningún archivo `.css`.
2. Abrir `dist/index.html`: referencia `https://cdn.tailwindcss.com` y un `@import url('https://fonts.googleapis.com/...')`.
3. Abrir la app con la red bloqueada (o con el CDN caído): el layout se rompe por completo.
4. Medir en DevTools: el CSS se inyecta en runtime (decenas de estilos generados por JS) después de descargar ~100 KB de un tercero.

## Current Behavior
- `index.html` carga Tailwind por CDN (`<script src="https://cdn.tailwindcss.com">`) y las fuentes por `@import`.
- `package.json` no declara Tailwind ni PostCSS; no hay `tailwind.config.*` ni hoja de estilos de entrada.
- El build copia `index.html` tal cual: producción sin CSS propio.

## Expected Behavior
CSS compilado en el build (Tailwind v3 + PostCSS, o v4 con `@tailwindcss/vite`), servido como asset hasheado; fuentes self-hosteadas o, como mínimo, con `preconnect` y `display=swap` sin bloquear el render. Sin dependencias de terceros para que la app se vea bien.

## Business Rules
- BR-001: La app no depende de `cdn.tailwindcss.com` en producción.
- BR-002: La estética y las utilidades usadas se conservan (mismas clases, mismo resultado visual).
- BR-003: El CSS generado se sirve desde el dominio propio con hash y cache inmutable (ya cubierto por `.htaccess`).
- BR-004: El build falla si Tailwind no genera el CSS esperado.

## Acceptance Criteria
- AC-001: GIVEN `dist/` generado WHEN lo inspecciono THEN existe al menos un `.css` con las utilidades usadas y ninguna referencia a `cdn.tailwindcss.com`.
- AC-002: GIVEN la app cargada sin acceso al CDN de Tailwind WHEN la abro THEN el layout y los estilos se aplican igual (comparación visual contra `screenshots/`).
- AC-003: GIVEN las fuentes WHEN se cargan THEN no hay request bloqueante a Google Fonts (o está self-hosteada).
