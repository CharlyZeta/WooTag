# ID: FIX-0026
# Status: DRAFT
# Mode: GATE

## Intent
La suite (146 tests) cubre bien los parsers y la API, pero deja sin red justo las capas donde aparecieron los bugs: `services/realtimeSession.ts` tiene 42% de líneas, `services/firebase.ts` 0% e `utils/ipLogger.ts` 0%, y no hay ni un test de `App`, `Controls`, `ImportTab`, `Tag`, `PriceAuditModal` ni de los modales. Los defectos de FIX-0011 y FIX-0012 habrían sido detectados por un test de integración mínimo.

## Reproduction Steps
1. Ejecutar `npm run test:coverage`.
2. Leer la tabla: `realtimeSession.ts` 42,3% líneas, `firebase.ts` 0%, `ipLogger.ts` 0%.
3. Buscar archivos de test de componentes: solo `TagSheet`, `MobileScannerView` y `AuthContext`.
4. Buscar tests de `App.tsx`, `Controls.tsx`, `ImportTab.tsx`, `Tag.tsx`, `PriceAuditModal.tsx`: no existen.

## Current Behavior
La cobertura se limita a `utils/**` y `services/**` (por configuración de `vite.config.ts`), y dentro de esos directorios hay huecos grandes. La capa de UI y el orquestador de estado no tienen ninguna verificación automatizada; `PriceAuditModal`, `ConnectionModal`, `CloudLoginModal`, `HostRoomModal`, `MobileJoinScanner` y `QrScannerModal` tampoco.

## Expected Behavior
Existe cobertura mínima en las capas críticas, con tests que representen los flujos que ya fallaron:
- `realtimeSession`: crear/unir/cerrar sala y `guestJoined`.
- `App`/`Controls`: alta de producto por cada vía y no-duplicado.
- `Tag`: formateo de precio con oferta, sin decimales, sin separador de miles.
- `PriceAuditModal`: agregar/descartar pendientes.

## Business Rules
- BR-001: Umbral mínimo acordado para `realtimeSession` y `firebase` (por ejemplo 80% de líneas).
- BR-002: Al menos un test de integración que cubra el flujo "agregar producto → aparece en la hoja".
- BR-003: Los tests nuevos referencian el criterio que cubren (convención SDD-GL: `AC-XXX`/`BR-XXX` en el nombre).
- BR-004: El umbral se aplica en CI cuando se acuerde (si se aplica, no debe bloquear el deploy por deuda previa).

## Acceptance Criteria
- AC-001: GIVEN `npm run test:coverage` WHEN termino THEN `realtimeSession.ts` y `firebase.ts` superan el umbral acordado (≥ 80% de líneas).
- AC-002: GIVEN un test de `Tag` WHEN se renderiza un producto con oferta y `showDecimals: false` THEN el precio mostrado es el esperado (`$1.234`).
- AC-003: GIVEN un test de integración de alta WHEN agrego un producto THEN aparece en `TagSheet` y la sincronización se invoca una sola vez.
