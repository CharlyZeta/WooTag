# CONTRACT: tagConfig y designProfiles se escriben en Firestore en cada cambio, sin debounce
# ID: FIX-0013
# Status: DRAFT
# Mode: GATE
# Gate-Mode: EXPRESS

## Intent
Cada cambio de configuración de la etiqueta dispara un `setDoc` inmediato a Firestore. Arrastrar un slider de tamaño de fuente o cambiar filas/columnas genera decenas de escrituras por segundo, consumiendo cuota, ensuciando el historial de versiones del documento y compitiendo con la suscripción en tiempo real de otros dispositivos.

## Reproduction Steps
1. Iniciar sesión en la nube y abrir la pestaña **Diseño**.
2. Con la pestaña Network/DevTools abierta (o el panel de Firestore), arrastrar el slider de tamaño de título durante 2 segundos.
3. Contar las escrituras a `users/{uid}`.
4. Repetir cambiando filas/columnas en **Ajustes**.

## Current Behavior
`App.tsx` tiene dos `useEffect` que escriben sin debounce: uno para `config` → `updateCloudProfile(uid, { tagConfig: config })` y otro para `profiles` → `{ designProfiles: profiles }`. El efecto de productos sí tiene debounce de 1 s; la configuración no.

## Expected Behavior
Los cambios se agrupan y se persisten una sola vez por valor estabilizado (800–1000 ms), sin perder el último cambio, y sin escrituras mientras el usuario sigue interactuando.

## Business Rules
- BR-001: Máximo una escritura de `tagConfig` por cambio estabilizado, con el mismo debounce que ya usa `products`.
- BR-002: No se pierde el último cambio: si el usuario deja de interactuar, el valor remoto converge con el local.
- BR-003: La carga de un perfil o la aplicación de un diseño guardado no debe multiplicar escrituras.
- BR-004: Sin cambios en la UX (no hay botón "Guardar").

## Acceptance Criteria
- AC-001: GIVEN un usuario autenticado con perfil cargado WHEN mueve un slider generando 20 cambios en 2 s THEN se ejecuta como máximo 1 `setDoc` con `tagConfig`.
- AC-002: GIVEN un único cambio de configuración WHEN pasan 1,5 s THEN el `tagConfig` remoto es igual al local.
- AC-003: GIVEN la misma prueba con `designProfiles` WHEN guardo y borro perfiles en ráfaga THEN se agrupan en una escritura.
